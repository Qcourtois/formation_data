# Exploratory Data Analysis (EDA)

## Intro :

L'objectif de l'**analyse exploratoire des données** est de transformer les observations brutes en informations : trouver des patterns, des tendances et des relations entre les données. 

### Objectif du projet :
Utiliser les outils Python et Pandas pour faire de l'EDA sur des données provenant de Gapminder.

## Description :
Notebook documenté fourni, que j'ai rempli en étudiant des données elles aussi fournies.
