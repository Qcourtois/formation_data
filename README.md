# formation_data

Présentation non exhaustive de mini-projets/exercices Data réalisés dans le cadre de ma formation Data Analyst.

## Intro:

Ce repo a pour objectif de démontrer mes capacités en programmation et de montrer mes compétences en gestion et analyse de données. Compétences acquises lors de ma formation de Data Analyst au sein du Campus Numérique in the Alps mais aussi d'expériences antérieures.

## À noter :
- Bien qu'avant de push sur GitHub je m'efforce de contextualiser les projets, de nettoyer mon code et de le documenter au maximum, cela reste un étalage de projets à but pédagogique ayant servi à acquérir des compétences ; ils ne possèdent pas la rigueur dans le code et la documentation que je pourrais fournir dans un projet professionnel.
- De plus, ils suivent souvent une structure et des consignes définies et ne représentent donc pas toujours mes choix personnels concernant le traitement et la gestion de données.

  ### Ulisation de l'IA :
  Conscient de la nocivité de l'IA pour le processus d'apprentissage, je me suis forcé à limiter au maximum son utilisation au sein de la formation. Les très rares occasions où j'ai eu recours à l'IA pour générer du code seront explicitement spécifiées dans la documentation.
